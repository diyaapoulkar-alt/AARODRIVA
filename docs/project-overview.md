# AARODRIVA AI — Project Overview

**Theme:** Space Technology & Disaster Management  
**Focus Region:** Brahmaputra Flood Basin, Golaghat District, Assam  
**Tagline:** *Detect. Locate. Rescue. Protect.*

## Core Value Proposition
AARODRIVA AI connects space-based Earth Observation with ground-level disaster rescue logistics. While satellites detect flood inundation, ground rescue teams lack real-time visibility into submerged road causeways and cut-off settlements. AARODRIVA AI automates marooned village identification, captures citizen distress signals with simulated NavIC coordinates, and calculates flood-avoiding rescue routes using Dijkstra's algorithm.
